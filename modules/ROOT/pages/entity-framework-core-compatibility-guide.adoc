= Entity Framework Core Compatibility Guide
:description: Compatibility between EFCore Provider, EF Core, .NET Frameworks, and the Couchbase .NET SDK.



[abstract]
{description}


.Compatibility
[cols="1,1"]
|===
| Couchbase EF Core Provider | 2.0.0-beta.2
| EF Core | 10.0.8
| .NET Version | .NET 10 ^①^
| Couchbase Server | >= 7.6.0
| Couchbase .NET SDK | >= 3.9.3
|===

① May work with other .NET versions, but not tested.
